# 分时图二次开发记录

本文记录本地分时图的定制改动，供后续维护和同步上游时核对。

## 个股详情分时 K

文件：`frontend/src/components/EChartsIntraday.tsx`

- 悬停到某一分钟时，在价格信息栏显示该分钟收盘价相对昨收的涨跌幅，保留正数的 `+` 号并显示两位小数。
- 仅在存在有效昨收时展示；鼠标移出后恢复默认汇总信息，不显示悬停涨跌幅。
- 对应回归覆盖位于 `frontend/src/components/EChartsIntraday.test.tsx`，检查悬停显示 `-1.46%`，移出后涨跌幅消失。

## 自选/列表分时图

文件：`frontend/src/components/stock-table/MiniIntraday.tsx`

- 支持「自适应 / 涨跌停」纵轴模式。涨跌停模式以昨收为中心展示价格带；当实际行情超出涨跌停带时，纵轴仍覆盖实际数据，避免曲线被裁切。
- 可叠加 9:15–9:25 集合竞价价格轨迹，并支持匹配量与未匹配量；竞价与连续竞价共用价格刻度。
- 支持底部成交量带。分钟成交量和竞价量各自在价格区下方呈现；无有效量数据时不占用价格图区域。
- 当日分钟 K 与竞价数据复权口径不一致时，按首根分钟开盘价与竞价末价的比例校正竞价价格，以保持走势连续。

集合竞价数据加载与共享配置位于 `frontend/src/lib/intraday-auction.ts`；相关价格、成交量和竞价绘制测试位于 `frontend/src/components/stock-table/`。

## 维护约定

- 涨跌幅按 `(分钟收盘价 - 昨收) / 昨收 × 100%` 计算；单位为百分数，仅用于前端展示。
- 调整图表行为时，保持 `EChartsIntraday` 与 `MiniIntraday` 各自职责，不在详情图和列表迷你图之间复制另一套数据加载逻辑。
- 修改集合竞价序列时，价格、匹配量、未匹配量应沿用同一扩展表和时间轴配置；缺失或无效数据应降级为不绘制对应图层。
